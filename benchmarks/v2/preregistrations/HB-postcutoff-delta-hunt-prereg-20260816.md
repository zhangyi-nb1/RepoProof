## 1. 网络窗口纪律(待 D5 批准)

- **一个窗口**。窗口内只做两件事:按 §2 过滤器**选择**候选、**拉取并封存**。
  不做盲攻、不做评分、不看任何"这题好不好打"的信号 —— 选择只按过滤器,
  防"看到分数再挑"。
- 目标:**2–3 个仓、合计 5–10 个 delta 候选**。单发候选对上准入死亡率是赌博
  (host2 教训:形态未经检验就开拉,封存后全灭)。
- 每候选封存(与 `rt-sidecar-browser-v1` / host2 同一条纪律,**封存不重下**):
  parent 源树、delta 测试件(单独目录)、post 树(答案区)、该仓 wheelhouse
  (macOS arm64)、题面原文、`candidate_manifest.json`(repo / SHA 对 /
  merge 日期 / diff 统计 / license / 拉取时间)。
- 窗口结束即断网;此后一切步骤离线。

## 2. 候选过滤器(硬条件,窗口内唯一的选择依据)

1. **merge 日期 ≥ 2026-06-01**(晚于在用模型的知识截止,留余量);
2. **PR 自带新增测试**(新增测试文件或函数;FAIL_TO_PASS 属性不在窗口内
   验证 —— 由 §5 基线步骤离线实测,B7);
3. 实现 diff **≥ 30 行**(不计测试与文档);
4. 实现改动集中于**单一模块**(一个包/文件族);
5. 非纯文档 / 依赖 bump / 格式化 / 重命名;
6. License 为 OSI(MIT / BSD / Apache-2.0 优先);
7. **离线可建**:纯 Python 或轮子可得,无 gcc / 系统依赖;套件单跑 ≤ 60s;
8. origin 与出题方均非本人(D1:换宿主同时换出题方);
9. 题面存在:PR 描述或关联 issue 足以公开陈述需求 —— 题面不成立的候选
   直接不拉(先教后杀:验收语义必须可公开)。

## 3. 离线准入流水线(每候选,顺序固定)

```text
① prep 自证        剥离 + 泄漏扫描(指纹源 = post 实现 diff)+ 扫描器自证
                   (植入答案必须报、干净树必须不报;prepare_host2 同款)
② oracle 卫生      四环境(COLUMNS/TZ/LANG/TMPDIR)全绿、四跑数字一致、
                   零 skip、耗时 ≤ 60s
③ 基线             parent 树 + 全部测试(旧 + delta):旧全绿、delta 恰好
                   全红(= FAIL_TO_PASS 实测,B7;两个方向都拒绝测量)
④ 盲攻             §5 协议,单发
⑤ 评分             scripts/blind_attack_admission.py(B1–B9):
                   ratio = 攻击后 delta 转绿数 / delta 集大小;
                   回归破坏单列 regression_broken,不掺 ratio
⑥ 残差分类         失败的 delta 条目逐条分类(行为 / 措辞);全散文残差
                   由判据自动归零(M64c)
⑦ 判决             heldout_admission.judge(0.95 线;没量过 = 判死;
                   沉默不是通过)→ 记录落 docs/evidence/heldout_admission/
```

## 4. 剥离清单(交付树)

`.git`(答案就是下一个 commit,一条 `git log -p` 即满分)、`.github`、
delta 测试件、`__pycache__` 及全部字节码、`.pth`/`.egg-link`、CHANGELOG
(可能逐条描述该 delta)。docs 是否剥离按候选判:凡描述 delta 行为的文档
页必剥,并记入该候选的 prep 报告。**剥离后必跑泄漏扫描 + 自证** ——
"我删了"是动作,"捞不出来"才是结论。

## 5. 盲攻协议

- **攻击者**:最强可用模型。每候选 ≥ 1 发;**拟当选**候选须 ≥ 2 个互不
  通气的攻击者(各自独立记录);
- **输入**:交付树 + 题面原文 + 依赖源码(deps-only venv —— **严禁**把被测
  包 editable 装进去,`.pth` 指回原件是实测过的取回路径);
- **禁**:隐藏 oracle、post 实现、后续历史、网络、给定路径之外的文件系统;
- **允许**:对自己写的代码做导入/语法检查;
- **单发不迭代**(允许迭代 = 在跑公开面调参,量的是公开面带宽不是先验
  可推导性);
- `method` 必填:攻击者身份、协议原文、材料清单 —— 判据挡不住敷衍,
  只挡得住没人量过;敷衍的攻击由 method 供人复核。

## 6. 判决与记法

- **准入合格**:ratio < 0.95 且残差含行为类且 ①–③ 全过 → 候选进入
  "可出题池",发次另立预注册;
- **判死**:任一环节红 → 记录在案,候选出局,**不回炉改线**(0.95 是
  实测地板定的,改它要新的实测,不是新的直觉);
- **有效 null**:全部候选判死 → "从 M 仓 N 候选全部判死"入 EXPLORATION_LOG
  与台账口径。null 只有在 N ≥ 5 时才有分量 —— 这就是 §1 批量纪律的理由。

## 7. 停止规则与变更纪律

- 窗口内发现过滤器歧义 → 按**更严**方向执行,回来记附录,不现场放宽;
- 本预注册冻结后改动一律附录制(正文不动);
- 彩排(§8)未全绿前不得申请开窗。

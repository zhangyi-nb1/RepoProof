## 4. 五实验协议与预期(判据先行,预期与实况分记)

通用红线:栈本体只经 machinery 变更;OfferClaw 主开发目录硬护栏不变;
**首跑实况一律入账不得改写;揭示缺陷 → 停-修-钉死-复跑,循环全程留痕。**

### R-A 顶层回滚 + 重施(direct)
真栈:`rollback_top(expect=f3)` → 断言树 == S2 冻结值、账面 active=S2、
apply_assist.py 缺席;S2 副本 verify(f1,f2)过;`apply f3 --requires f2`
→ **状态复用断言:回 S3 同 id 同树**。预期:PASS。

### R-B 级联撤销(composite)
真栈 S3(f3 declared requires=[f2]):`removal_plan(f2)` → kind=cascade,
cascade_order=[f3,f2](LIFO);`cascade_remove(f2)` 未带确认 →
`CascadeConfirmationRequired`(栈零变);部分确认(只 f3)→ 同拒;
全链确认 → 退到 S1,断言树 == S1 冻结值 + verify(f1) 过。
随后重建:apply f2 → S2 同树;**apply f3(独立身份,不带 requires)**
→ S3 同树(requires 不进树,只进台账)——为 R-C 铺设独立前提。
预期:PASS。

### R-C 选择性移除(selective_rebuild)
真栈 S3(f3 独立):`removal_plan(f2)` → kind=selective_rebuild;
`selective_rebuild(f2)`:scratch = S1 + 重放 f3 → 全量验证
(verify-cmd 桥:`drive_t4.sh verify-last f1,f3 rc-scratch`,scratch
路径 root-last)→ 通过则真栈等价变换(LIFO 退 + 重施 f3)→
断言真栈树 == scratch 树(重建确定性),新状态 S3′ ≠ S3
(research_jobs.py 缺席),verify(f1,f3) 过。
预期:PASS(f3 与 f2 的组合面仅 requirements.txt union,f3 不 import f2)。
若全量验证不过 → `SELECTIVE_REMOVAL_NOT_SAFE` + 栈零改动,同为合法结果
(记录实况)。

### R-D 写回后人工漂移 → 回滚必须零写拒绝
**在栈+台账副本上**(/tmp,真栈不动):S3 后手改 apply_assist.py
(模拟用户在特性落地后自行编辑)→ `rollback_top`。
**预期首跑:FAIL(诚实预登记)** —— 现行 `rollback()` 只校验 preimage
完整性,不检查当前盘上内容,将直接用 preimage 覆盖用户手改(clobber);
feature_stack 的 `_finalize_rollback` 树校验会在覆盖**之后**才失配报错
——为时已晚,手改已丢。实况(clobber 字节证据)入账后进入停修循环:
修 `rollback()` 为三态检查(current==after_hash→恢复;
current==preimage→幂等跳过;其他→`DriftDetected` **零写拒绝**,两阶段
先检完再动手)→ 钉死测试 → 复跑 → 预期 `PROJECT_DRIFT_DETECTED`
且盘上手改一字节不动。**本实验的产出 = 该缺陷的实证 + 修复。**

### R-E 施加中崩溃 → 无静默半态
**在栈+台账副本上**:
(a) 进程内中断:`_atomic_write` 第 2 笔时抛 KeyboardInterrupt
(BaseException,绕过 `except Exception`,与 kill 同构)→ journal
滞留(phase=applying)→ 一切新操作被 `StackJournalPending` 拒绝 →
`recover_interrupted` → 树 == 父状态冻结值,journal 清除;
(b) 进程外硬杀:驱动脚本把 `_atomic_write` patch 成慢写,子进程
apply,外部 `kill -9` → journal 在盘 → recover 同判据。
回滚相崩溃:rolling_back 相中断 → recover 幂等重放回滚 → 回父状态。
预期:PASS(§26 journal-before-write 设计,合成 fixture 已钉死;此处
在真特性包上复证)。

### 静息态恢复(实验后,非实验)
R-C 结束于 S3′;恢复:rollback f3 → S1,apply f2 → S2 同树,
apply f3(独立)→ S3 同树(与冻结值逐字节同)。栈静息于 S3。
